# 알로소 제품 가격 카탈로그

시리즈 → 타입 → 사양 → 방향 → 등급 → 소재 → 아티클 → 컬러 순으로 고르면
제품코드, 규격, 소비자가, 프로모션가를 보여줍니다.

## 폴더 구성

    index.html      카탈로그 화면 (단일 파일)
    data.json       가격 데이터 1,877행
    img/p/          품목 이미지 3,446장
    img/s/          컬러 스와치 43장

## GitHub Pages 올리기

1. 저장소를 만들고 이 폴더의 내용을 그대로 올립니다.
2. Settings → Pages → Source를 main 브랜치 / root 로 지정합니다.
3. 1~2분 뒤 https://<계정>.github.io/<저장소>/ 에서 열립니다.

## 할인율 바꾸기

화면 오른쪽 위 할인율 칸의 숫자를 바꾸면 프로모션가가 즉시 다시 계산됩니다.
계산식은 소비자가 × (1 − 할인율), 천 원 단위 반올림입니다.

## 데이터 고치기

data.json의 rows 배열을 고칩니다. 각 행의 키는 아래와 같습니다.

    se 시리즈   ty 타입    sa 사양    di 방향
    gr 등급     ma 소재    ar 아티클
    c1 세트코드1  c2 세트코드2  cp 구성
    sn 세트명   sp 규격(WxDxH)  pr 소비자가

colors는 아티클별 컬러 목록, img.p는 세트코드1별 컬러→이미지 파일명,
img.s는 아티클별 컬러→스와치 파일명입니다.
